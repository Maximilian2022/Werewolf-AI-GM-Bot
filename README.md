# 人狼 AI GM Bot (Werewolf AI Game Master Bot)

**Discordのボイスチャンネル** や **Zoomミーティング** を活用し、人狼ゲームの進行・司会（ゲームマスター / GM）を全自動で行うAI GM Botシステムです。

ゲームの開始アナウンスから役職の個別配布、昼の議論タイマー、投票集計、夜の個別アクション受付、朝の犠牲者発表、勝敗判定、そして感想戦のAI講評（MVP選出）まで、スムーズな音声合成（TTS）とチャットUIで進行を強力にサポートします。

> [!NOTE]
> **AI支援による開発についての明記**  
> 本プロジェクトのソースコード、ゲームルール調整ロジック、Webダッシュボード、および各種ドキュメントは、AIアシスタントの協力を得て設計・実装・テストされています。

---

## 🌟 主な特徴

- **🎙️ 音声による自然なGM進行**  
  Google Cloud Text-to-Speech による自然な日本語音声で、フェーズの切り替えや結果の発表をリアルタイムにアナウンスします。
- **👥 複数Bot（Worker）による並行個室案内**  
  Discordでは夜フェーズになると、占い師や霊媒師、騎士などの各個室へ専用のスタッフBotが同時に接続し、個別に音声案内を行います。
- **📹 Zoomミーティング連携対応**  
  Discordだけでなく、ZoomミーティングへBotを召喚してゲームを進行できます。ブレイクアウトルームを活用した夜の個室移動や、ミーティング内チャットコマンドによる進行に対応しています。
- **🛡️ 豊富な役職ラインナップ（30種以上）**  
  村人・人狼・占い師などの標準役職から、ハンター、独裁者、罠師、悪女、女王、棺桶屋など、多彩な特殊役職に対応しています。
- **📊 直感的なWeb管理ダッシュボード**  
  ブラウザから配役の人数調整やルール設定（初日白通知、連続護衛、議論時間、Zoom連携設定など）を簡単に行えます。
- **🧠 ゲーム終了時のAI総評・MVP発表**  
  Gemini AIがゲーム中のログを分析し、村のレギュレーションやプレイヤーの活躍を踏まえたMVPの表彰と講評を行います。

## 🚀 かんたんスタートガイド

### 【Discordで遊ぶ場合】

#### 1. 準備するもの
- Discordアカウントおよび管理者権限を持つDiscordサーバー
- ゲームに参加するプレイヤー（4名以上推奨）

#### 2. ゲームの始め方
1. 参加者全員で、サーバー内の任意のボイスチャンネル（例: 「一般VC」）に入室します。
2. テキストチャンネルで以下のスラッシュコマンドを実行します。
   ```text
   /開始
   ```
3. Botが自動的に「昼の議論VC」「人狼VC」「霊界VC」「個別待機部屋」をセットアップし、参加者をそれぞれの部屋へ移動させてゲームがスタートします。

#### 3. ゲーム中の操作
- **昼の議論**: 画面に表示される残り時間タイマーを見ながら話し合います。
- **投票**: 自分の発言ターンになったら発言し、ボタンを押して処刑したい相手に投票します。
- **夜の行動**: 各自の個別テキストチャンネルに選択ボタンやメニューが表示されます。案内に従って夜の能力を実行してください。

---

### 【Zoomで遊ぶ場合】

Zoomミーティング上でも、Botを参加させて人狼ゲームを楽しむことができます。

#### 1. 準備するもの
- Zoomアカウントおよびミーティングルーム（ホスト権限または共同ホスト権限を推奨）
- Webダッシュボードへのアクセス

#### 2. ゲームの始め方
1. Webダッシュボード（`/ダッシュボード` またはブラウザ）を開き、**「📹 Zoom連携」** タブを選択します。
2. Zoomミーティングの招待URL（またはミーティング番号・パスコード）を入力し、**「ミーティングに参加（召喚）」** をクリックします。
3. BotがZoomミーティングに参加します。準備ができたら、Zoomのミーティング内チャットで以下を送信するか、ダッシュボードから開始します。
   ```text
   !開始
   ```

#### 3. Zoomミーティング内チャットコマンド
| コマンド | 説明 |
| :--- | :--- |
| `!開始` | ゲームを開始します。 |
| `!一時停止` | 議論タイマーを一時停止します。 |
| `!再開` | 一時停止した議論を再開します。 |
| `!ヘルプ` | チャット内でコマンド一覧を表示します。 |

> [!TIP]
> Zoom利用時は、夜フェーズになるとBotが参加者を自動的にブレイクアウトルーム（個別待機室・人狼作戦部屋など）へ移動させ、朝になると自動でメインルームへ呼び戻します。

## 📋 Discord スラッシュコマンド一覧

| コマンド | 説明 |
| :--- | :--- |
| `/開始` | ゲームを開始します。（レギュレーションや読み上げの指定も可能） |
| `/廃村` | 進行中のゲームを強制終了し、作成されたチャンネルを片付けます。 |
| `/一時停止` | 議論タイマーや夜の制限時間を一時停止します。 |
| `/再開` | 一時停止したゲームを再開します。 |
| `/ダッシュボード` | Web管理画面（レギュレーション調整・各種設定・Zoom連携）のURLを表示します。 |
| `/レギュレーション` | 登録されているレギュレーション一覧と役職構成を確認します。 |
| `/再解析` | 直前のゲームログをもとに、AI総評（MVP）を再実行します。 |

## 💻 Web管理ダッシュボードの使い方

Botが起動している状態で `/ダッシュボード` を実行するか、指定のURLにアクセスするとWebダッシュボードが開きます。

1. **Discordログイン**: ダッシュボードを開き、Discordアカウントでログインします。
2. **役職の配分設定**: レギュレーションビルダー画面で、参加人数に合わせて各役職の枚数を `+` / `-` ボタンで調整します。
3. **ルールオプション**:
   - 初日の占い（白通知 / 自由占い / なし）
   - 騎士の連続護衛（あり / なし）
   - 決選投票同票時のルール（ランダム処刑 / 処刑なし）
   - 霊媒結果の発表有無
   - 夜の人狼VC会話の許可
4. **プリセット保存**: 設定した配役をカスタムレギュレーションとして名前を付けて保存できます。
5. **Zoom連携制御**: Zoomタブからミーティングへの参加・退出、ブレイクアウトルームの制御、仮想シミュレータによるテスト実行が可能です。
