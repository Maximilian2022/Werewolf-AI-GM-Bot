📖 Discord Bot & Tunnel 設定ガイド

1

Cloudflare Zero Trust で Tunnel を作成

Cloudflareダッシュボードの [Zero Trust] ➔ [Networks] ➔ [Tunnels] で新しいトンネルを作成します。取得した Token を左の入力欄に貼り付けます。

2

Public Hostname (公開ドメイン) の設定

Tunnelの [Public Hostname] で以下を指定します：

  • Domain: 左欄で入力したFQDN（例: gm.your-domain.com）
  • Type: HTTP
  • URL: localhost:3000
3

Discord Developer Portal での OAuth2 設定

Discord Developer Portal で対象Botを開き、[OAuth2] タブへ移動します。

  • Redirects: 以下のURLを追加して保存します：
    https://<FQDN>/api/auth/discord/callback
  • Client Information: [Client ID] と [Client Secret] を左欄に入力します。
4

Privileged Gateway Intents の確認

[Bot] タブで以下の3つのインテントがすべて ON になっていることを確認してください：

PRESENCE INTENT SERVER MEMBERS INTENT MESSAGE CONTENT INTENT
5

Bot のサーバー招待 (OAuth2 URL Generator)

[OAuth2] ➔ [OAuth2 URL Generator] で以下を選択して生成されたURLからサーバーへ招待します：

  • Scopes: bot, applications.commands
  • Bot Permissions: チャンネル閲覧、メッセージ送信、埋め込みリンク、リアクション追加、VC接続、発言
6

Discord コマンドでのダッシュボード案内

Botが導入されたサーバーで /ダッシュボード と入力すると、設定した公開FQDNへのアクセスリンクが表示されます。ゲーム参加者への案内や設定確認にご活用ください。

📖 Zoom Private App (Meeting SDK) の事前準備・設定ガイド ▼

1. Zoom アカウントの設定（必須）

主催者のZoom設定画面（zoom.us/profile/setting）で、以下を有効にしてください：

  • ブレイクアウトルーム: 「ミーティングにて（高度）」内のブレイクアウトルームを ON にし、「スケジューリング時にホストが参加者をブレイクアウトルームに割り当てることを許可」にチェック。
  • 共同ホスト: 「ミーティングにて（基本）」内の共同ホストを ON。

2. Private App（Meeting SDK）の作成手順

  1. Zoom App Marketplace にアクセス。
  2. 「Meeting SDK」 アプリを選択して「Create」をクリック。
  3. アプリ名（例: Werewolf GM Bot）を入力し、公開はせず Private（社内/開発用） として保存。
  4. App Credentials タブから Client ID と Client Secret をコピーし、当ダッシュボードの「プロファイル管理」に登録してください。

3. ゲームの進め方

Botがミーティングに参加したら、Zoomのチャットに !開始 と打つか、上記「ゲームを開始する」ボタンを押せば、自動で役職配布・昼夜の部屋移動が開始されます！

4. 1人で動作確認・実機テストを行う方法

【案2: ブラウザ多重参加による実機テスト】

  • Google Chromeで「新しいプロファイルを追加」するか、シークレットウィンドウ / 別ブラウザ（EdgeやFirefox）を開きます。
  • Zoom参加URLを開き、「Zoom Meetings を開く」のポップアップをキャンセルします。
  • 画面下部に現れる 「ブラウザから参加する (Join from your browser)」 をクリック。
  • アカウントログイン不要で名前だけ入力すれば、1台のPCから3〜5人分のタブを並べて同時参加させられます！

【案3: 自分1人だけのミーティング疎通テスト】

  • 参加者を集めず、自分1人だけのミーティングにBotを召喚します。
  • チャットで !ヘルプ を送って返信が来るか、マイクからBotのTTS音声が聞こえるか、ホストキーで権限が渡るかを1対1で最小検証できます。
