📖 Discord Bot & Tunnel 設定ガイド

1

Cloudflare Zero Trust で Tunnel を作成

Cloudflareダッシュボードの [Zero Trust] ➔ [Networks] ➔ [Tunnels] で新しいトンネルを作成します。取得した Token を左の入力欄に貼り付けます。

2

Public Hostname (公開ドメイン) の設定

Tunnelの [Public Hostname] で以下を指定します：

  • Domain: 左欄で入力したFQDN（例: gm.your-domain.com）
  • Type: HTTP
  • URL: localhost:3000
3

Discord Developer Portal での OAuth2 設定

Discord Developer Portal で対象Botを開き、[OAuth2] タブへ移動します。

  • Redirects: 以下のURLを追加して保存します：
    https://<FQDN>/api/auth/discord/callback
  • Client Information: [Client ID] と [Client Secret] を左欄に入力します。
4

Privileged Gateway Intents の確認

[Bot] タブで以下の3つのインテントがすべて ON になっていることを確認してください：

PRESENCE INTENT SERVER MEMBERS INTENT MESSAGE CONTENT INTENT
5

Bot のサーバー招待 (OAuth2 URL Generator)

[OAuth2] ➔ [OAuth2 URL Generator] で以下を選択して生成されたURLからサーバーへ招待します：

  • Scopes: bot, applications.commands
  • Bot Permissions: チャンネル閲覧、メッセージ送信、埋め込みリンク、リアクション追加、VC接続、発言
6

Discord コマンドでのダッシュボード案内

Botが導入されたサーバーで /ダッシュボード と入力すると、設定した公開FQDNへのアクセスリンクが表示されます。ゲーム参加者への案内や設定確認にご活用ください。

📖 Zoom Meeting SDK App 作成手順＆利用ガイド（完全無料）

💡 完全無料（$0）・クレジットカード登録不要: Meeting SDK App の作成および Client ID / Secret の取得には費用は一切かかりません。グループまたは参加者のうち最低1人がキーを持っていれば利用可能です！
STEP 1

Zoom アカウントの設定

主催者のZoom設定画面（zoom.us/profile/setting）を開き、以下を ON にします：

  • ブレイクアウトルーム: 「ミーティングにて（高度）」内のブレイクアウトルームを有効にし、「スケジューリング時にホストが参加者を割り当てることを許可」にチェック。
  • 共同ホスト: 「ミーティングにて（基本）」内の共同ホストを有効化。
STEP 2

Marketplaceでアプリ作成

  1. Zoom App Marketplace (作成画面) にログイン。
  2. 「Meeting SDK」（または General App）を選択して 「Create」 をクリック。
  3. アプリ名（例: Werewolf GM Bot）を入力します。
  4. 公開審査は不要です（社内・プライベート開発用としてそのまま利用可能）。
STEP 3

OAuth設定 & Scopes（権限）

アプリ設定画面の各項目に以下を入力・選択します：

  • OAuth Redirect URL:
    https://jinrougmbot.kenko.land
    （または https://example.com 等のhttps形式URL）
  • OAuth Allow Lists:
    https://jinrougmbot.kenko.land
  • Scopes (権限): 「Add Scopes」➔「Meeting」から以下を追加：
    - meeting:read:meeting (閲覧)
    - meeting:write:meeting (BOルーム管理等)
STEP 4

認証キーを取得して登録

  1. アプリ設定画面の 「App Credentials」 タブを開きます。
  2. Client ID と Client Secret をコピーします。
  3. 当画面上部の「プロファイル登録・編集」フォームに貼り付け、「プロファイルを保存する」 をクリック！
STEP 5

ゲームの開始と自動進行

「ミーティング参加」タブへ戻り、ミーティングURLを入力して召喚します。

  • Zoom内チャットで !開始 と送信すると自動でゲーム開始。
  • 夜フェーズになるとBotが参加者を個室や人狼部屋へ自動移動させ、朝になるとメインルームへ呼び戻します！
🧪 1人で動作確認・実機テストを行うおすすめの方法
① 仮想シミュレータ（画面内で即テスト）
「ミーティング参加」タブの「🧪 仮想シミュレータ起動」を押せば、Zoom不要でダミー参加者（5〜13人）が生成され、チャットや部屋移動の挙動を即座に確認できます。
② ブラウザ多重参加（実機Zoomテスト）
Chromeのシークレットウィンドウや別プロファイルからZoom参加URLを開き、「ブラウザから参加」を使えば、1台のPCから複数タブで同時参加させてテスト可能です。
